# MAKU（幕間機）仕様

プロジェクト名は MAKU。もとは Felucca（Leo Kuroshita、GPL-3.0-only）。画面・起動画面・コンソール・USB の INFO の表示名は MAKU に替えた。USB のデバイス名、ローダーの識別子、パッケージの識別子、`FELUCCA_*` のビルドオプション、ファイル名は、互換と履歴のためそのまま。

DJイベントなどで、ささっとつないでとりあえずの音を出す機械。
電源を入れた瞬間から、その場限りのアンビエンスが**常に鳴っている**。パラメータに触れるほど盛り上がっていく。

MAKU（docs/MAKU.md）を本体にし、それ以外の機能は大胆に捨てる。

## 原則

- 設定してから鳴らすのではない。電源を入れたら、もう鳴っている（最初の約0.8秒は無音からふくらむ。小さなスピーカーで、MASTER を上げたままでも叫ばないため。エミュレーターにはない）。
- 保存はしない。起動するたびに、**ランダムなパラメータ**から始まる。例外は「いいね」だけ（REC で記録した世界。下記）。
- 1つのパラメータに細かく触れられることに価値はない。回せば良い方向に動くことに価値がある。
- 画面遷移もメニューもない。ボタン1つが動詞1つで、押せばすぐに音で返ってくる。

## 4つの役（トラック）

| # | 役 | 中身（MAKU） |
|---|---|---|
| 1 | 脈 | キック（DRUM） |
| 2 | 床 | ドローン（PHYS） |
| 3 | 霞 | シマー（GRAIN） |
| 4 | 声 | アルペジオのフレーズ（PHYS） |

起動時には、音源、音色、根音、スケール、テンポ（例：70〜90 BPM）、各トラックの3つのパラメータをランダムに決める。素材の幅は、残す音源の範囲（PHYS・GRAIN・DRUM、ANALOG は候補）で持たせる。

## 操作子

- **KNOB 1〜4**：トラック1〜4の**音量**。この役割は常に変わらない。
  - 少しでも回すと、そのトラックに**フォーカス**が移り、画面がそのトラックの内側になる。
- **SELECT / PRESETS / ALGORITHM**：フォーカス中のトラックの3つのパラメータ。どれも、回せば盛り上がる方向に動く。
- **MASTER**：全体の音量（ハードウェア）。
- **鍵盤**：押した音がそのまま鳴る。音はフォーカス中のトラックの声になる。スケールで補正しない。アボイドノートもスパイスとして鳴らす。

## ボタン（1つに動詞1つ）

| ボタン | 動詞 | 振る舞い |
|---|---|---|
| HOME | 振り直し | 長押しで、新しいランダムな世界に移る |
| SEQ | テンポ | 押している間、SELECT が BPM（1刻みで1。MIDIクロックが来ていれば追従する）、PRESETS が SWING（アルペジオの揺れに足す）、ALGORITHM が DUCK（キックが他を沈める深さ。64 が従来）。トラックごとのゲインとソロはない（黒鍵のミュート、C4 の全解除、F4 のタップテンポは残る） |
| ARP | 根音・スケール | 押して離す（タップ）たびに、スケールが MAJ → MIN → LYD → DOR → MIX → PHRY → PEN → MPEN → MAJ …とメジャー系とマイナー系が交互に巡る。押している間は、弾いた鍵の音に根音が移り、SELECT が ROOT（半音）、PRESETS が SCALE（上の順）、ALGORITHM が REG（ドローンの音域 LOW / MID / HIGH）になる |
| OCT− / OCT+ | 転調（五度圏） | 押すたびに根音が五度下（♭が1つ増える）／五度上（♯が1つ増える）へ移る。移調ではなく調号の付け外し：すでに弾かれた音（溶け込んでいる音、進行中のアルペジオのフレーズ）は高さを保ったまま、調号が変える1音だけが半音動く（C→G で F→F♯）。7音でないスケールでは、新しい調に元の高さがない音は、調号が動く向きの半音隣へ、なければ最寄りの構成音へ寄る。旧スケールの外の音（鍵盤で弾いた回避音）は弾いた高さのまま。鳴っている和音は鳴り止むまでそのまま、次の和音から新しい根音で始まる。鍵盤のオクターブ操作はない |
| PLAY | 漂う（DRIFT）のスイッチ | タップで DRIFT のオン／オフ。オンの間は PLAY が緑に点灯する。押している間は RATE / RANGE / REACH が SELECT / PRESETS / ALGORITHM に出て、つまみを回したときは、離してもオン／オフは変わらない。オンの間、値が少しずつ（ランダムウォークで）動き、止めても離した場所に残る。動くのは、4パート×3つのマクロ（ただしキックの密度 SELECT は動かさない）。REACH が 43 以上なら空間（キック以外の送りと、マスターの高域）も、86 以上ならテンポ・SWING・DUCK も（テンポは内部クロックのときだけ）。オンにした瞬間の値から RANGE の半分より遠くへは行かない（テンポだけは RANGE に比例した幅で、最大 ±16 BPM）。オンの間に手で動かした値は、その値が新しい基準になる。新しい世界ではオフに戻る |
| SAVE | （機能なし） | 弾いた音は、押さなくても常に場のフレーズへ溶け込む（下記「決まったこと」） |
| REC | いいね | タップで、いま鳴っている世界を「いいね」に記録（LED が点く）。約2秒の長押しで、いいねを全部消す（下記「好みが育つ」） |

上段の6つ（FX SCL ENV LFO EDIT GLO）は**一度押すと数秒効いて、ゆっくり戻る変化の動詞**。それぞれが別の軸を持ち、同じ資源を2つの動詞が触らない。押している間と、離してから HOLD の間は満タン、そのあと FADE で戻る（下記「動詞の時間」）。効かせる量は動詞ごとに固定で、つまみで変えられるのは時間だけ。

| ボタン | 動詞 | 軸 | 振る舞い |
|---|---|---|---|
| FX | 潜る（SINK） | 奥行き：奥へ沈む | キックが消え、キック以外のリバーブ送り・ディレイ送り・リバースが約0.5秒で深まる。同時に、リバーブの尾のフィードバックが 0.995 近くまで上がり、響きが吸い込まれていく。戻るときは、キックが最後の6分の1でフェードインし、潜りも戻る。量はフィードバック 100、送り 127、キックは完全に消える（固定）。時間の既定は RISE 0.5拍 / HOLD 4拍 / FADE 3.8拍 |
| SCL | 降り注ぐ（CASCADE） | 音域と音数：上へ広がる | アルペジオが全ステップで鳴り（息継ぎの5ステップも）、1オクターブ上・2オクターブ上が重なり、スケールの3度上が重なる。量は固定：毎ステップの発音確率 120/127、オクターブ上が2つ、3度上が重なる確率 110/127。量に沿って、戻りながらこれらが起きる確率が薄れる |
| ENV | 膨らむ（SWELL） | 時間：長く伸びる | **押した瞬間に、床と霞が今の和音をもう一度打つ**（アタックは同時に伸びるので、和音がゆっくり膨らみ直す）。床・霞・声のこれから鳴る音のアタックとリリースが、上限へ寄る。和音が続く確率（STAY 100/127）：持続する方は次の和音を打たずに今の和音を鳴らし続け、打つ方は同じ和音を繰り返す。STAY は床と霞だけに効く（声のアルペジオには効かない）。時間の既定は RISE 1拍 / HOLD 8拍 / FADE 11.5拍 |
| LFO | 揺れる（WOBBLE） | 動き：周期的に揺れる | 床・霞・声のフィルターLFOが速く深くなり、コーラスの送りが上がり、ピッチが揺れる（RATE 127 / DEPTH 127：フィルターLFOの深さとコーラスの送り / PITCH 100：ピッチLFOの深さ。固定） |
| EDIT | 持ち上げる（LIFT） | 音色：前へ、明るく、硬く | 4トラックすべての TONE マクロ（PRESETS）が頂点（127）へ寄り、キック以外の歪みが最大 +80 増え、マスターのハイパスが全域まで上がる（高域が残り低域が細る）。固定。RISE の既定が長い（約2.9拍）ので、せり上がるように効く |
| GLO | 崩す（SCRAMBLE） | 秩序：拍とフレーズが崩れる | アルペジオが表のあちこちへ跳び、再抽選が増え、**ときどき連打（×2〜4）する**。キックのゴーストが最大 +60 % 散り、ゴーストと手で置いた拍が連打（ロール）し、手で置いた拍が**ときどき抜ける**（0拍目は残る）。アルペジオの揺れが最大 +70 増える。固定（ARP 110 / KICK 127 / SWING 127） |

対になる組：SINK（奥へ）と LIFT（前へ）、SWELL（ゆっくり・長く）と SCRAMBLE（細かく・乱れる）、CASCADE（音が増える）と WOBBLE（音は増えず揺れる）。

### キックにフォーカスしているとき

キックは音の高さより、鳴る位置が大事。キックのトラックにフォーカスしている間だけ、鍵盤は16ステップのシーケンサーになる。

- **白鍵16個**：ステップ1〜16。押すとそのステップがオン／オフ。ACC（黒鍵9）を押しながらだと強拍。LED は鳴るステップが点灯し、再生位置が反転して流れる。
- **手で打った拍は、常に鳴る。** 密度（SELECT）は、その上に足す「ゴースト」の確率になる。ゴーストは保存しない。
- **黒鍵1〜8**：サーッというノイズやチリッとした音の装飾パッド。押すと鳴るだけで、パターンは変わらない（暗い方から：ライド2のシャリ、ロングギロのこすれ、ペダルハット、カバサ、タンバリン、マラカス、オープンハット、スプラッシュ。クラップやスネアのような胴のある音は入れない）。黒鍵9は ACC、黒鍵10・11は無機能。
- **密度（SELECT）がキックの並びを決める。** 4〜39でステップ1が気配から確かに、40〜67でステップ9が、68〜95でステップ5・13が加わり、**96以上で4つ打ち（1・5・9・13）が確率100%**になる。96を超えると、キックには触らずに装飾音（同じ DRUM トラックのハット）が確率で足されていく：裏拍（3・7・11・15）のオープンハットは96から立ち上がって127で確実に、そのほかの16分（偶数番の弱拍）のクローズハットは104から最大60%。ボイスが足りなくなるので、96を超えると持続する床のコードは2声（根音と5度）になる（打つ床は下記 OPEN の声数のまま、最大3声）。

### ボタンのパラメータ（動詞の共通の決まり）

HOME 以外のボタン（動詞）は、押している間に、画面の3つの区画がその動詞の3つのパラメータ（名前・値・ゲージ）に入れ替わり、SELECT / PRESETS / ALGORITHM で動かせる。上段の6つは **RISE / HOLD / FADE（拍）**、SEQ は BPM / SWING / DUCK、ARP は ROOT / SCALE / REG、PLAY は DRIFT の RATE / RANGE / REACH（画面の見出しに ON / OFF）。SEQ・ARP・PLAY の値は次の HOME 長押し（新しい世界）まで残る。上段の6つの時間は、新しい世界でも残る（電源を切ると既定値に戻る）。KNOB 1〜4（各トラックの音量）は動詞を押している間も変わらない（SEQ と ARP の間だけは何もしない）。SAVE と REC（いいね）にはパラメータがない。

動詞が動かした値は、戻りの終わりに元の値（その間にマクロが書いた値があればそれ）に戻る。

### 動詞の時間（上段の6つ）

量（0〜1）が、押すと **RISE** で上がり、押している間と、離してから **HOLD** は 1 のまま、そのあと **FADE** で S字に 0 へ戻る。長さは拍で、テンポに付いてくる（外部クロックにも）。つまみの 0〜127 を指数で割り当てる：RISE 1/4拍〜8拍、HOLD 0 と 1/2拍〜32拍、FADE 2拍〜32拍。1 に達する前に離しても上がりきる（タップは1周）。戻りの途中でもう一度押すと、今の量から上がり直して HOLD もやり直す。動詞ごとに別の時計で、重ねがけできる。LED は、効いている間は点灯、FADE の間は息をする。確率で効く所は量に比例するので、戻りに沿って薄れる。設計は docs/VERBS_TUNE_PLAN.md。

動詞の設計と、外した旧動詞（FREEZE・TAPE・SWEEP・REPEAT・ハーモナイザー・RISE・KEEP・TWIST・FOG）の経緯は docs/VERBS_PLAN.md と docs/decisions.md。

## 画面：操作子の物理配置と揃えた4分割

240×240 の画面を 120×120 の4つの区画に分ける。各区画は、画面の左にある 2×2 のつまみの位置に対応させる。

```
 本体のつまみ              画面
┌────────┬────────┐   ┌──────────┬──────────┐
│ MASTER │ SELECT │   │ 波形      │ SELECT の │
│        │        │   │ BPM・音量 │ パラメータ │
├────────┼────────┤   ├──────────┼──────────┤
│PRESETS │ALGORITHM│  │ PRESETS の│ALGORITHM の│
│        │        │   │ パラメータ │ パラメータ │
└────────┴────────┘   └──────────┴──────────┘
```

- **左上（MASTER の位置）**：波形を表示する。あわせて、どのモードでも次の3つを常に表示する。
  - BPM の数字
  - 4トラックの音量を示す細いバー（KNOB 1〜4 の並びの順）
  - フォーカス中のトラック
- **右上・左下・右下**：それぞれ SELECT・PRESETS・ALGORITHM が今動かしているパラメータの名前と値。
- **すべてのモードを同じ様式で表示する。** ボタンを押している間に、3つのつまみの役割が変わるモード（SEQ のテンポなど）も同じ。役割が変わったつまみの区画だけ表示が入れ替わる。
- 1つのモードに割り当てるパラメータは**最大3つ**。区画に収まらないページ送りは作らない。

## 残すもの

- MAKU の生成ロジック、4トラックのミキサー、8ボイス、ダッキング、スケール処理
- 空間系エフェクト（リバーブ、ディレイ、コーラス）とリミッター。ただし触れるパラメータとしては出さない
- 演奏系エフェクト（リピート、テープストップ、フリーズ、フィルタースイープ、ハーモナイザー）のコード（perform.c）とそのテスト。これらを動詞として割り当てることはやめた（下記「ボタンのパラメータ」）。ボタンの動詞は上段の6つ（SINK など）が受け持つ
- MIDIクロック入力（追従のみ。主役にはしない）
- ファームウェア更新の経路（ローダー、OTA、USB、インストーラー）。公式ファームウェアに戻すため必須
- ブラウザエミュレーター

## 決まったこと（実装済み）

各トラックの3つのパラメータ（1つのつまみが、最大3つの実パラメータを同時に動かす）。右に回すほど盛り上がる。

| トラック | SELECT | PRESETS（音色） | ALGORITHM |
|---|---|---|---|
| 1 脈 | DENS（密度） | TONE：TONE↑、SNAP↑、DECY↓。PULSE キックでは TONE が厚いキックから ECG のビープへ移る（80 から、110 で純粋。100 からビープが最大 +4 半音昇り、1オクターブ上が重なる）。TONE 95 以上では DENSITY の装飾ハットが高い正弦のピップになる | WASH：リバーブ送り、ディレイ送り、DRV |
| 2 床 | OPEN：和音の声数（2〜4。持続する床では常に3声で、上限が2のときは2声。下記「音色の幅」）。中央（64）より下は間延び：次の和音を打たず前の和音を鳴らし続ける（最大70%） | TONE：BRIT、BUZZ | SWAY：コーラス、フィルターLFO、リリース |
| 3 霞 | GRAIN：DENS↑、SIZE↓。中央より下は間延び：音を間引く（最大90%） | TONE：TONE、SPRD、RAND | AIR：リバーブ、ディレイ、アタック |
| 4 声 | LOOSE：ほどけ（再抽選）と昇り（1オクターブ上）。中央より下は間延び：音を間引く（最大65%） | TONE：BRIT、DAMP↓、ACC | TRAIL：ディレイ、リバーブ、リリース |

- 起動時と HOME 長押しで、床・霞・声の音色（プリセット）と、全マクロの値がランダムに決まる。
- 弾いた鍵の音は、次のアルペジオのステップでまず鳴る。鍵盤で弾いた音は、REC を押さなくても常に声のフレーズへ溶け込む（キックにフォーカスしているときの鍵盤はステップなので除く）。最新の8音を覚え、フレーズのステップごとに35%で、覚えている音から1つが鳴る。音は鳴るたび・試すたびに薄れ、弱い音ほど鳴らなくなる。9音目からは、いちばん古い（いちばん薄い）音が押し出される。スケール外の音は、さらに拾われにくく、薄れるのも2倍速い。
- HOME を押しながら OCT− を押すと、設定メニュー（色、LEDS、画面オフ、キャリブレーション）が開く。メニューを閉じるのは HOME。LEDS の既定は AUTO：電池駆動なら DIM LO、USB ホストがつながっていれば DIM HI。電池駆動で残量が 3 本中 1 本以下になると、左上に BATTERY LOW（0 本は BATTERY EMPTY）を約2秒出す（そのレベルが5秒続いてから。1本減ったら即、その後は2分ごと）。ふだんは画面に何も出さない。これらの実装箇所は `grep -rn MANNER: firmware`（docs/UI_RULES.md 10）。
- CC20 は、キックの SELECT（密度）。

## 好みが育つ：いいね（実装済み）

いいと思った世界を REC で記録すると、HOME 長押しの振り直しのたびに、その好みから世界が再生され、ときどき少し変わる。いいねが増えるほど好みへ固まる。使う人ごとに、その人の好みに育つ（`firmware/src/maku_fav.c`）。

- **いいねリング**：最大16件（`MAKU_FAV_MAX`）。満杯なら最古が押し出される。1件に持つのは、maku_world が決める状態そのもの：seed、床／霞／声の音色（カタログの安定ID）、ROOT、SCALE、BPM、マクロ12個、床と霞の INSERT（種類、RATE、DEPTH、FDBK）、床と霞のピッチの揺れ段階（段階がなかった頃のいいねは WARP、つまり当時の音のまま）。押した時点の値（手で回したマクロ、DRIFT が動かした値、ARP や OCT で変えた調も）を記録する。
- **REC**：タップ（約2秒より前に離す）でいいねを1件記録。長押し約2秒（`MAKU_FAV_CLEAR_MS`）で全消去。いいねした世界の間は REC の LED が点き、次の世界で消える。
- **振り直し**：有効ないいねが N 件あるとき、確率 r = min(90 %, 15 % × N)（`MAKU_FAV_STEP`、`MAKU_FAV_CAP`）で、いいねから1件を選ぶ（直近ほど重い。重みは古い順に 1, 2, …, N）。残りは完全ランダムな新しい世界。N = 0 なら従来と同じ（同じ seed で同じ世界、ビット一致）。
- **変異**：選んだいいねの要素（床・霞・声の音色、ROOT、SCALE、マクロ12個、ピッチの揺れ段階）を、それぞれ独立に約8 %（`MAKU_MUT_P`）で別の値に引き直す。引き直し先は新しい世界と同じカタログの重み・範囲。BPM と INSERT は変えない。変わった世界を気に入って REC すれば、それが新しいいいねになる。
- 抽選と変異は振り直しのときだけ（メインループ、ISR ではない）。選び方は seed から別の乱数列で引くので、同じいいねと同じ seed なら同じ世界。起動時（と #seed=N）は従来どおりランダムで、いいねを使わない。
- **カタログは追記のみ**：各行に安定ID。既存の行のID・意味は変えない（変えるなら新IDの行を足し、古い行は重み0で引退。いいねからは引き続き鳴る）。MAKU_CATALOG_VERSION は評価ログのキーだけで、いいねを捨てない。読み出しで未知のIDや範囲外の値を含む1件は読み飛ばし、他は残す。
- **保存**：実機は REC を押したとき（記録・消去とも）だけフラッシュに書く（RESTORE LAST の autosave が使っていた A/B セクタ 0xE5000 / 0xE6000 に、別の型で）。振り直しや通常動作では書かない。1回の REC は書き込み4回だけ：書く側のセクタは先に消しておく（電源オン時と、次の新しい世界のとき。4 KB の消去は約40 ms 音を止めるので、押した瞬間にはしない）。消去前の掃除が間に合っていないとき（新しい世界の前に REC をもう一度押したとき）だけ、押したときに消去し、その間は短いフェードの凹みで包む（audio.c SOFT）。構造体に版とチェックサムがあり、壊れていれば空で起動する。エミュレーターはフラッシュの模擬ごと localStorage に保存される。Felucca/MAKU 同士の更新では残るが、公式V15に戻す（M-VAVE のアップデータを含む）と消える。
- 出荷時は空。初期のいいねは入れない。

## 音色の幅：出し方と声のカタログ（実装済み）

音は「エンジン＋プリセット」だけでなく、**出し方（ART）**と組で世界ごとに決まる（`maku_voices.c`、設計と測定は docs/VOICES_RATING.md）。

| 出し方 | 立ち上がり | 持続 |
|---|---|---|
| STRK 打つ | 即 | 短い（今までの音） |
| SOFT 柔らかく打つ | 約0.15秒 | 短い |
| SWEL ふくらむ | 約2秒 | 次の音まで保つ（TIE） |
| BOW 擦る | 約0.5秒、励起が続く | 次の音まで |
| HOLD 置く | 約1.4秒 | 和音が変わるまで |

- 床は9通り、霞は5通り、声は10通り。床の約8割と霞の約8割が持続系で、**床と霞の少なくとも一方は必ず持続**。
- 持続系の床と霞は DIV 1/8（和音は約7秒ごと）。声の SWEL / BOW は「ゆっくりした旋律」：4ステップに1音、次の音まで保つ。
- ボイスはパートごとに上限がある（床と霞は持続するときだけ：持続する床は3、ただし PHYS の床と密度96超では2。持続の霞は2。声は2で、密度96超では1。キックは上限なし、密度96超では2）。ATK / REL のマクロは持続系では土台の前後だけ動く。

## 空間系の味付け（実装済み）

このファームウェアに入れた時点で、MAKU 以外のモードはない。そこで、3つのバスに個性を持たせた（`firmware/src/fx.c`）。ウェット側はステレオで返る。

- **コーラス**：2タップのアンサンブル。左右が別の LFO（右はやや遅く、3分の1周ずれる）で揺れる。声が散って、像が開く。
- **ディレイ**：テープ。読み出し位置がゆらぎ（ワウ・フラッター）、フィードバックは低域が削られ、ソフトクリップで少しつぶれる。繰り返すたびに、暗く、薄く、荒くなる。右は同じ線の 3/4 の位置を聴く（別のリズムになる。バッファは増やしていない）。
- **リバーブ**：ROOM に 25 ms のプリディレイ。4つのコムのうち2つの読み出し位置が、ゆっくり動く（尾が一点で鳴り続けず、うっすら揺れる）。コムを左右に別々の割合で混ぜて、広がりを出す。SPRING は従来どおり（モノを両側へ）。
- **逆再生リバーブ**：リバーブの戻りを1拍ずつ録り、逆向きに再生する。2乗で立ち上がって、拍の頭に向かってふくらみ、拍で切れる。2つのバッファを交互に使い、半分のレートで録る（0.74秒まで）。量は、霞の AIR で決まる（約20より上で入ってくる）。

## 処理負荷の見積もり

ホスト（Linux）上で測った見積もり（実機は未測定）。全体のミックスの ns/サンプルを測り、docs/MAKU.md の旧 MAKU（密度127、約 1739 命令/サンプル、実機でおよそ30%）との比で換算した。

| 状態 | 旧 MAKU 比 | 実機の見積もり |
|---|---|---|
| 旧 MAKU（密度127） | ×1.0 | 約 30% |
| 今の世界の最悪（密度127、OPEN・LOOSE 127） | ×1.7 | 約 51% |
| 同じ最悪に FREEZE・ハーモナイザー・REPEAT・LPF を全部押さえる（外した旧動詞での測定。今のボタンでは起きない） | ×2.1 | 約 63% |

- 空間系の味付けで、全体に約 +4.5% 足された（静かなときも、バスは常に動く）。
- オーバーロード時の保護（2ブロック続けて 85% を超えると、ボイスを1つずつ減らす）は残っている。最悪のときでも、そこまでは約20%の余地がある。
- 換算は ns の比によるもので、実機の命令数やキャッシュの違いは入っていない。実機で確かめるまでは、目安として扱う。

## INSERT（試用中）

Felucca 1.5 の INSERT（トラックごとの歪み・フェイザー等）を、ドローンとシマーにだけ使っている。耳と負荷で残すか決める。削除の手順は docs/decisions.md。

- 世界ごとに決まる：種類と速さは下の「ピッチの揺れ段階」による（STILL：ドローンは PHASR / なし、シマーはなし / 遅い CHOR。SWAY：ドローンは PHASR / CHOR / なし、シマーは FLANG / CHOR / なし。WARP：ドローンは CHOR、シマーは FLANG / CHOR）。速さ（RATE）は 0.1〜0.5 Hz（STILL は約0.2 Hz まで）、戻し（FDBK）は世界ごとにランダム、深さ（DEPTH）は SWAY / AIR マクロが動かす。キックとアルペジオには付けない。
- 動かすのは各 TONE マクロ（ドローン：MIX 20〜110、シマー：GRAIN マクロの MIX 0〜90）。なしの世界では何も起きず、負荷もかからない。
- 実機用ビルドの実測：フラッシュ +2.0 KB、RAM +0.1 KB、プール +2.3 KB。オーディオ割り込みの静的な負荷は変わらない。ホストでは、両方に PHASR を最大にかけて旧 MAKU 密度127 の +15〜20%（実機では約 +5 ポイントの見積もり）。

## ピッチの揺れ段階

ピッチを揺らす要素を、世界ごとに床（ドローン）と霞（シマー）それぞれ1つの段階で抑える（`maku.c` `MAKU_PM`）。

| 段階 | 確率 | 霞 GRAIN の RAND（粒ごとのランダムなデチューン） | 揺れる INSERT（FLANG / CHOR）の DEPTH |
|---|---|---|---|
| STILL | 70 % | 6〜18（最大 ±24セント） | 20〜60 |
| SWAY | 22 % | 10〜40（最大 ±1.2半音） | 30〜100 |
| WARP | 8 % | 0〜100（最大 ±7半音） | 30〜127 |

- 両方が WARP にはならない（そのときは床が SWAY）。片方が必ず落ち着いた錨になる。
- 段階は上限なので、マクロ・LIFT・DRIFT をどこまで動かしても超えない。WOBBLE の PITCH（押している間の揺れ）は対象外。
- RAND は逆再生の粒の割合も決めるので、STILL では逆再生の粒も少ない（最大約14 %）。
- アルペジオにはピッチを揺らす要素がない（コーラスのセンドだけ）ので段階を持たない。

## 未決（実装しながら決める）

- 起動時ランダムの範囲。どこまで振れても「いい感じ」に収まるか。耳で調整が必要。
- 4つの音量を同時に上げたとき、音同士が避け合う動き（ダッキングの拡張）。
- ゴースト（密度が足すキック）を LED で暗く表示すること。
- いいねの定数（16件、15 %、90 %、8 %、2秒）を耳で決める。
- RESTORE LAST の行、使わない音源（FM6・SAMPLE・LOFI・WHEEL・VOICE・TRIO・PHASE・NOISE）の削除。音源を表から外すだけなら、フラッシュは約28KB減る（試した）。ただし ui_test.c（約7,300行）が、これらの音源の画面とレイヤーを前提にしていて、外すと多くが落ちる。画面側（ページ、レイヤー、編集画面）とテストを一緒に整理する必要がある。
