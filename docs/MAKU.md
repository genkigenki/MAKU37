# MAKU(幕間)— 生成ロジックの設計メモ

> **注意：これは、MAKU がまだ「MENU で入る1つのモード」だった頃のメモです。** いまの MAKU は、電源を入れたときから常に鳴る専用機で、操作も画面も替わりました。現在の仕様は [AMBIENT.md](AMBIENT.md)。ここに残るのは、4トラックの生成ロジック（キック、ドローン、シマー、アルペジオ）の考え方です。MENU の MAKU 行、RESTORE LAST との関係、CC20 の記述は、もう当てはまりません。

> M-VAVE FM-1 用ファーム Felucca 1.1.5.1 に、**幕間(まくあい)のアンビエントマシーン**「MAKU」を足した派生版です。
> ライセンスは元の Felucca と同じ GPL-3.0-only。実機での動作は作者が確認済みです(書き込みは自己責任)。なお、この文書は旧「モード」形態の設計メモで、現行仕様は AMBIENT.md が優先します。

## これは何か

つまみ1本(**DENSITY / 密度**)で、次の3つを一つの流れとして育てたり、しずめたりする機能です。

| 密度 | 起きること |
| --- | --- |
| 0 | ドローンと高いきらめきだけ。幕間の「空気埋め」 |
| 4〜39 | キックが**気配**として小節に1回、だんだん確かに |
| 16〜 | アルペジオ(カリンバ)が散らばり始める |
| 40〜79 | キックが**脈**になる(2拍ごと)。キックでドローンが沈む(ダッキング) |
| 80〜127 | キックが**拍**になる(毎拍)。アルペジオは崩れて密になる |

密度を下げると、崩れていたものが**元の整った形に戻ります**(往復で高揚感が出るように作ってあります)。

## 最短で試す(実機なし)

```sh
web/emu/build.sh          # 初回は ./build.sh も必要(Emscripten が要る)
python3 -m http.server -d build/emu 8790
```

http://localhost:8790/ を開くと、**初回訪問ならすでに MAKU が ON、密度 48** で始まります。画面の **PLAY** を押すと鳴ります。
HOME 画面で **KNOB 1** を回すと密度が変わります。

> 以前にそのブラウザでエミュレータを開いていて曲が保存されていると、自動では ON になりません。下の「ON にする」を使うか、サイトデータを消してください。

## ON にする / 密度を動かす(はじめての人向け)

1. **HOME を長押し**してメニューを開く。
2. **ALGORITHM** のつまみで **SYSTEM** タブへ。**PRESETS** のつまみで **MAKU** の行へ。
3. **OCT+**(または KNOB 1〜4)で **ON**。**HOME** を押してメニューを閉じる。
4. **PLAY** を押す。
5. **HOME 画面**(HOME ボタンで戻れる)で **KNOB 1** を回す。上に「DENSITY n」と出ます(0〜127)。

そのほかの動かし方:

- **MIDI CC20**(どのチャンネルでも)= 密度 0〜127。MAKU が ON のときだけ効きます。外部のつまみやフェーダーに割り当てられます。
- **SELECT** つまみは元どおりテンポ(ON にすると BPM は 72 に設定されます)。
- キー(調)は **SCL** ページの ROOT / SCALE。**どのトラックで変えても4トラック全部に反映**されます(初期は C マイナー)。キックの音程はルートに追従せず固定です。

OFF は同じ行を OFF にするだけです。ただし**音色とパターンは MAKU 用のまま残ります**(元に戻すには音色をロードし直すか、保存したプロジェクトを開く)。

## 4つのトラック

| トラック | 役 | 音 | ステップ数 | 中身 |
| --- | --- | --- | --- | --- |
| 1 | キック | DRUM の PULSE キック(KICK=PULSE): TONE が低いと太くどっしりしたキック、TONE を上げると心電図のビープ(1ヒット1回の短い「ピッ」)へクロスフェード(80 から混ざり始め、110 以上で心電図音のみ。100 以上では音程が最大4半音上がり、1オクターブ上の高い音が重なる。TONE 95 以上では、密度を上げたときに足されるサブ音(ハット)がシンバル系ではなく約2kHzの高い「ピー」になる) | **16** | 密度で間引く時間軸。※「共振器キック」は未実装で、この既存キックで代用しています |
| 2 | ドローン | PHYS DRONE STRING | **57** | 19 ステップごとに和音。開いた響き(ルート+5度+オクターブ、sus2、sus4、広い短10度、2度クラスター)が6種、ゆっくり巡る |
| 3 | きらめき | GRAIN CLOUD PAD | **13** | 高い単音と、その7ステップ後の5度ペア。6音のサイクル |
| 4 | アルペジオ | PHYS KALIMBA | **29** | 書き込み済みの32個のフレーズ(広い跳躍、休符入り)から、ランダム位置でN歩(3〜8)連続→別の位置へジャンプ。29歩のうち最後の5歩は無音(息継ぎ) |

- **キック以外のステップ数は 57 / 13 / 29。いずれも 16 の倍数ではなく、互いに割り切れないので、位相がずれ続けます。** ドローンの 57 ときらめきの 13 が同じ位置で揃うのは 741 ステップに1回です。
- 音は**常にスケール内だけ**です(調を変えても外れません)。
- **崩し/整え**: 密度が上がるほど、アルペジオの音の振り直し、スウィング、ベロシティの揺れ、ランが短くなる、が増えます。
- **ダッキング**: キックが鳴るたびにドローンが沈み(密度 127 で約 0.56 倍)、約0.12秒で戻ります。

## 元の Felucca からの変更点

**増えたもの**

- MENU > **SYSTEM** タブに行 **MAKU**(OFF/ON)。CALIBRATION と ABOUT の1つ前。SYSTEM タブは4行→5行。
- MAKU が ON のとき、HOME 画面の **KNOB 1 = DENSITY**(通常のサウンド用つまみを置き換えます。他の KNOB 2〜4 は従来どおり)。
- **MIDI CC20 = DENSITY**(他の CC は変更なし)。
- 新ファイル `firmware/src/maku.c`、テスト `tests/maku_test.c`、設計メモ `docs/decisions.md`(日付つき1行ずつ)。
- エミュレータ(`web/emu`)は、初回訪問で MAKU を ON(密度 48)にして始めます。

**変えていないもの**

- 通常の演奏・シーケンサ・保存の形式、プロジェクト/ユーザープリセットの形式、エディタのプロトコル(パラメータ番号は不変)。
- MAKU が OFF のとき、**既存の92個の音の出力は1ビットも変わりません**(回帰テストで確認)。

**注意(ふつうの Felucca と違う点)**

- MAKU は**保存されません**(電源を入れ直すと OFF)。ON にした瞬間に4トラックの音色・パターンを**上書き**するので、大事な曲があるときは先に保存してください。
- MAKU ON の間、各トラックに保存された自分のステップは**鳴りません**(MAKU が代わりに鳴らします)。OFF にすると元のステップ演奏に戻ります(ただし ON にしたときに空にされています)。
- RESTORE LAST が ON の場合、電源を入れ直すと MAKU 用の音色が復元されるはずですが、MAKU 自体は OFF で始まるため**無音**に見えるはずです(この動きは実機で未確認)。もう一度 MAKU を ON にしてください。

## 動作の確認状況

- ホストテスト全部通過(MAKU 専用テストでは、キックの段階、57/13/29 ステップ、全16スケール・複数ルートでスケール外の音が出ないこと、息継ぎ、ダッキング、ボイス数を確認)。
- 実機用ビルド(`./build.sh`)は通り、割り込み処理の静的コストは MAKU 追加前とほぼ同じ(+0.15%)。
- CPU: 密度 127 で約 1739 命令/サンプル。リポジトリの換算(100 命令で約 1.7%)でおよそ **30%**(既存で最重の組み合わせより約10%重い)。余力は十分ですが、実機での測定は未実施です。
- ボイス: 密度 127 でも最大7/8、ボイスの横取りは0。

## 調整したくなったら(耳で決める箇所)

すべて `firmware/src/maku.c` と `firmware/src/ui.c` の `maku_setup()` にあります。

- キックの段階の境目: `maku_kick_chance`(4 / 40 / 68、`MAKU_FOUR` = 96 で4つ打ちが100%)。その上の装飾音: `maku_orn`
- 和音・きらめき・フレーズ: `MAKU_CHORD`、`MAKU_SHIM_A/B`、`MAKU_PHRASE`(数字はスケール度数。255 は休符)
- 音色: `maku_setup` の表(エンジンとプリセット番号)と REL(リリース。長くするとボイスが足りなくなるので `tests/maku_test.c` の VOICES で確認)
- ダッキングの深さ: `maku_step` のキック部分の `1800u`
