# 動詞の手触りの見直し（実装済み）

2026-10-11。上段の6つの動詞（SINK CASCADE SWELL WOBBLE LIFT SCRAMBLE）の押し方と効き方の見直し。現行の仕様は AMBIENT.md。
この文書は経緯と、決めた理由。

## 変えたこと

1. **押し方**：押しっぱなしをやめた。一度押すと効き始め、押している間と離したあとしばらくは満タンで、そのあとゆっくり元へ戻る。
2. **画面の3つのパラメータ**：効かせる量ではなく**時間**にした。全部の動詞で RISE / HOLD / FADE。効かせる量は動詞ごとの固定値
   （`MAKU_PEAK`）。
3. **効き方**：SWELL・LIFT・SCRAMBLE を派手にした。ただし他の動詞の資源には触らない。

理由：動詞のパラメータは、効かせながら触るのが難しく、3つの量は聞いても分かりにくかった。触るのは使う前で済む時間にして、量は
最大にした。

## 1. 時間：RISE / HOLD / FADE

```
 量
 1 ┤    ┌──────────────┐
   │   ╱ 押している間 + HOLD ╲
   │  ╱                      ╲___
 0 ┼─┘                           ╲________
   押す  離す   ←HOLD→    ←FADE（S字）→
   RISE
```

| 段 | 中身 |
|---|---|
| RISE | 押した瞬間から 0 → 1 へ上がる（直線） |
| 押している間 | 1 のまま |
| HOLD | 1 に達していて、離したあと、この長さだけ 1 のまま。長く押せば伸びる |
| FADE | 1 → 0。S字（始めも終わりもゆっくり）。最後の方は聞こえないほど小さく変わるので、いつの間にか戻っている |

- **長さは拍で数え、テンポに付いてくる**（`beat_samples`。外部クロックにも追従）。つまみ 0..127 を指数で割り当てる。

  | 区画 | 範囲 |
  |---|---|
  | RISE | 1/4拍 〜 8拍 |
  | HOLD | 0（つまみ 0）、1/2拍 〜 32拍 |
  | FADE | 2拍 〜 32拍 |

  画面は拍の数字（0.5、4.0、…）。72 BPM で 1拍は約0.83秒。
- 1 に達する前に離しても、上がりきる（タップは1周）。そのあと HOLD、FADE。
- 戻りの途中でもう一度押すと、今の量から上がり直し、HOLD もやり直す（延長）。
- 動詞ごとに別の時計。重ねがけできる。
- 時間は**新しい世界でも残す**（奏者の癖であって、世界の個性ではない）。電源を切ると既定値に戻る。
- 画面とつまみは、押している間だけその動詞の3つ（RISE / HOLD / FADE）。離したらマクロに戻る。
- 上段のボタンの LED：上がり・押している間・HOLD は点灯、FADE は息をする、0 で消灯。
- 既定値（つまみ。拍）：SINK 32 / 64 / 30（0.5 / 4 / 3.8：潜る 約0.4秒、浮かぶ 約3秒の元の性格）、SCRAMBLE 8 / 70 / 50、
  CASCADE 20 / 84 / 64、LIFT 90 / 60 / 64（せり上がる）、SWELL 50 / 84 / 80（膨らみ、ゆっくり手放す）、WOBBLE 30 / 84 / 64。耳で決め直す。
- 実装：`maku_env`（1ブロックごと。`va` は今まで通り Q12 で、効き目を決める所はすべて `va` を読む）。確率で効く所（CASCADE の発音、
  SCRAMBLE の跳躍、SWELL の STAY）は、`va` の分だけの確率で効くので、戻りに沿って薄れる。

## 2. 効き方

量の最大は固定（`MAKU_PEAK`）。生の最大値のままだと音楽にならない所だけ手前で止めた：WOBBLE の PITCH 100、CASCADE の DENSE 120 /
HARM 110、SCRAMBLE の ARP 110、SWELL の STAY 100。

### SWELL（時間）
- **押した瞬間に、床と霞が今の和音を打ち直す**（`dc[]` の最後の和音を、次のステップで1回。持続する声部も）。アタックは同時に伸びるので、
  和音がゆっくり膨らみ直す。
- ATTACK・RELEASE は「足す」でなく**頂点へ寄せる**（量 1 で上限）。元が短い音ほど大きく変わる。
- STAY は床と霞だけ（声のアルペジオには効かない）。

### LIFT（音色）
- TONE を**頂点へ寄せる**（全トラックの TONE マクロが 127 まで）。EDGE は歪みを最大 +80、THIN はマスターのハイパス全域（+100）。
- せり上がる動きは RISE を長くするだけで出る。

### SCRAMBLE（秩序）
- アルペジオが**連打**（RATCH ×2〜4、`seq_ratchet` が `maku_cur` の step を繰り返す）、跳躍、再抽選。
- キックのゴースト最大 +60 %、ゴーストと手で置いた拍が**連打**（ロール）、手で置いた拍が**ときどき抜ける**（0 拍目は残す）。
- SWING は最大 +70。

## 3. 動詞間の独立

VERBS_PLAN.md の原則（同じ資源を2つの動詞が触らない）を守るため、最初の案から外した：

| 外したもの | 理由 |
|---|---|
| SWELL が床・霞の音量を上げ、キックと声を下げる | キックの音量は SINK の資源。声の音量は DUCK とも重なる。音量を上げた余裕（クリップ）も実機で聞かないと分からない |
| SWELL の STAY を声に効かせる | アルペジオの音数・発音は CASCADE の資源 |
| LIFT が声と霞を1オクターブ上げる | 音域は CASCADE の SPAN の軸 |
| SCRAMBLE のオクターブの飛びと休符 | オクターブは SPAN、休符は DENSE の裏返し。CASCADE の軸 |
| SCRAMBLE の霞の打点のずれ | 実装を後回し（打つ声部の和音の巡りを崩さずにずらす手が要る） |

ATK の枠は SWELL と SINK が共有しているので、足し合わせでなく**大きい方**を取る（`maku_over`）。
