# Contributing to MAKU

Thanks for helping! To keep things easy to follow, please use the right place:

| What | Where |
|---|---|
| A bug you can reproduce | [Issues](https://github.com/okumurari2/maku/issues/new/choose): one issue per bug |
| An idea, a request, or a question | [Issues](https://github.com/okumurari2/maku/issues/new): say so in the title (no promise an idea will be added) |
| A bug or idea about Felucca itself | [hugelton/Felucca](https://github.com/hugelton/Felucca) |

## Reporting a bug

Please include the MAKU version (HOME + OCT- > ABOUT, or the package's file name), your computer's OS if the
installer or USB is involved, the steps to reproduce it, what you expected and what happened. A photo or a short
video helps.

## Pull requests

Pull requests are welcome, including AI-assisted ones, with the same bar for all:

- keep it small and focused on one thing;
- make sure you understand the change and can explain it;
- test it on a real FM-1 (or, for sound and behaviour, in the browser emulator);
- run `tests/run_tests.sh` (see [BUILDING.md](BUILDING.md));
- new files carry the GPL-3.0-only SPDX header.

By contributing you agree that your contribution is licensed under GPL-3.0-only.

MAKU has no web editor. Felucca's web editor and installer live in [Felucca-WebApp](https://github.com/hugelton/Felucca-WebApp).
